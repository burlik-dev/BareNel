Я ценю кастомизацию. Во всем без исключения. В загрузчиках тем более.
В связи с этим мною принято решение сделать BareNel Loader кастомизирующимся при помощи файла конфигурации.
Предполагается, что загрузчик используется только для загрузки ядра BareNel. Мультизагрузка не поддерживается (по крайней мере сейчас; нужна ли она вообще?).

Конфигурационный файл должен находится в директории BNL в корневом каталоге EFI раздела.
Синтаксис config.conf:
#Name=BareNel
#File=barenel
#Autoboot=1

Параметр Name отвечает за имя загрузочной записи, File - за путь файла ядра относительно корневого каталога, Autoboot - автозагрузка ВКЛ\ВЫКЛ.
